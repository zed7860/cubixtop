# Cubixtop India - Next.js

## Run locally
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Deploy to Vercel
Push this folder to GitHub, import the repository in Vercel, and deploy. No special build settings are required.

## Enquiry form
The API currently accepts and logs enquiries. Connect `app/api/enquiry/route.ts` to Resend, Supabase, or another service before production.
